# Roadmap

What we're working on, in the open. The fuller story, with what's already out, is on [woolshed.dev/roadmap](https://woolshed.dev/roadmap/).

- **Ideas** are [discussions in Ideas](https://github.com/woolshed-dev/woolshed/discussions/categories/ideas). Upvote the ones you want.
- **Planned** work is an issue labelled [`roadmap`](https://github.com/woolshed-dev/woolshed/issues?q=is%3Aopen+label%3Aroadmap).
- **Shipped** work is closed with the release it's in: see [Releases](https://github.com/woolshed-dev/woolshed/releases) and [What's new](https://woolshed.dev/changelog/).

We don't give dates we can't keep. Watch this repository (Releases only) to hear when something lands.
