# Helping Woolshed

The app's source isn't public, but there's plenty you can do here, and all of it helps.

## Report what you find

A good bug report is the most useful thing you can send: the version (Settings › Updates), your system, what you did, what you expected and what happened instead. Screenshots and the output of `hc server status` help. Use the [bug form](https://github.com/woolshed-dev/woolshed/issues/new?template=bug.yml).

Woolshed can draft a report for you: run `woolshed feedback "what happened"`, or ask your agent to.

## Shape what comes next

Upvote the issues you care about with a 👍 (we sort by them), and add what you'd use them for. Ideas start in [Discussions](https://github.com/woolshed-dev/woolshed/discussions/categories/ideas); the ones we commit to get the `roadmap` label.

## Make mods and layouts

Woolshed is built to be reshaped. A layout is a JSON file and a mod is a small JavaScript program, and your agent can write either in a sentence. Share yours in the [gallery](https://woolshed.dev/gallery/): put it in a public GitHub repository with the topic `woolshed-mod` or `woolshed-layout`, and it appears there. The [developer guide](https://woolshed.dev/developers/) covers the API.

Issues labelled [`good first issue`](https://github.com/woolshed-dev/woolshed/labels/good%20first%20issue) are mods, layouts and docs that someone new can pick up, with what done looks like.

## Spread the word

If Woolshed helps you, a ⭐ here, a post about what you built with it, or a mod in the gallery helps others find it.

## Be kind

Be patient and assume good intent. We remove anything abusive.
