# Getting help

| You have | Go to |
|---|---|
| A bug | [Report a bug](https://github.com/woolshed-dev/woolshed/issues/new?template=bug.yml) |
| An idea or a request | [Request a feature](https://github.com/woolshed-dev/woolshed/issues/new?template=feature.yml) |
| A question, or something to show | [Discussions](https://github.com/woolshed-dev/woolshed/discussions) |
| A security problem | [SECURITY.md](SECURITY.md), privately |
| Billing or your account | hello@woolshed.dev |

Before you write, the answer may already be in the [getting-started guide](https://woolshed.dev/start/), the [FAQ](https://woolshed.dev/#faq) or the [developer docs](https://woolshed.dev/developers/). Your agents can read the app's own manuals too: `woolshed --skill` and `hc --skill`.

## What to expect

- We read every issue and discussion, and aim to reply within 3 working days.
- For a bug, we'll ask for anything we need to reproduce it, say whether we can, and what happens next.
- When a fix or feature ships, the issue is closed with the release it's in, so you get a notification.
- If a request doesn't fit Woolshed, we'll say why and close it; it may fit as a mod, which anyone can write.
